# Archived Tauri prototype

This directory retains the previous Tauri/Rust implementation for reference.
It is not part of the active desktop runtime, frontend bridge, scripts, tests,
or installation packages. Historical paths in its configuration refer to the
old project layout and are not maintained as a runnable fallback.

The active desktop implementation is in `electron/`; the Vue frontend remains
in `src/`. See the project root README for the current Electron launch steps.
