# Archived browser prototype

These files preserve the initial Python HTTP implementation and its reference
tests. They are not used by the desktop app, frontend scripts, or packaging.
The active backend is in `apps/desktop/electron/`, exposed through Electron IPC
or the local browser-development bridge. See the project root README.

The prototype's static-file paths no longer match this archived location. It is
retained as implementation history, not as a supported runtime or fallback.
