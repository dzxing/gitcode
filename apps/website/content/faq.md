# 常见问题

## 需要服务器吗？

桌面应用直接操作本地仓库。获取、拉取、推送时连接你配置的 Git 远程服务。
门户网站与桌面应用独立部署，桌面运行不依赖门户在线。

## 应用自带 Git 吗？

不自带。请安装系统 Git，或在 Git 运行环境设置中选择已有可执行文件。
GitCode 支持 Git 2.30 或更高版本；建议使用仍有维护的 Git 版本。

## 支持哪些系统？

桌面工程提供 Windows、macOS 和 Linux 构建配置。
实际可下载的系统与架构以下载页公布的安装包为准。

## 如何读取 WSL 仓库？

Windows 版本可通过 WSL 目录访问发行版内的仓库。Git 命令在对应发行版执行，
需要发行版可运行，并且已安装 Git。Windows 与 WSL 使用各自的 Git 配置和凭据。
