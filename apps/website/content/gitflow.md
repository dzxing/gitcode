# GitFlow

GitFlow 将功能开发、发布准备与紧急修复组织为不同的分支流程。
GitCode 直接使用 Git 命令，无需另装 git-flow 扩展。

## 配置基础分支

打开仓库导航中的 GitFlow 操作面板，选择生产分支、开发分支及分支前缀。
基础分支缺失时，先确认已有远程分支或创建对应的本地分支，再开始开发。

## 开始功能开发

选择 Feature，输入名称并确认起点。开始后会创建并检出功能分支。
首次推送时确认目标远程，GitCode 将创建远程分支并设置上游。

## 完成功能或发布

完成前提交工作区变更，获取远程状态并检查合并目标。
在完成预览中核对目标分支和后续步骤；如发生冲突，先处理冲突再继续。
完成和推送是不同的操作，请根据团队约定确认远程同步。
