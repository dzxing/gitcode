# 快速开始

GitCode 使用本机 Git 操作仓库，无需为桌面应用部署服务器。

## 安装前准备

安装 Git 2.30 或更高版本。在终端运行 `git --version`，确认 Git 可以执行。
如果应用未能找到 Git，可在「设置 → Git → Git 运行环境」中选择可执行文件。

## 打开仓库

通过「文件 → 打开仓库」选择已有 Git 仓库目录。首次打开时确认仓库信任。
Windows 下的 WSL 仓库需要对应发行版已启动，并在发行版内安装 Git。

## 提交与同步

1. 在工作区查看文件差异，将需要提交的变更加入暂存区。
2. 输入提交说明，执行提交。
3. 使用「获取」更新远程跟踪分支；使用「拉取」将更新合并到当前分支。
4. 使用「推送」发布本地提交，首次推送时确认远程和目标分支。

有未处理冲突或正在进行的 Git 操作时，请先按应用提示完成处理。
